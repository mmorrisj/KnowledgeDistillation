With a prompt chosen, the teacher goes through the unlabelled pool and answers each message. Those answers become the student's training labels. This lesson is about what can go wrong between the two.

## Unusable replies

Some replies will not name a valid type. In Module 2 those counted as wrong when scoring the teacher. When building a training set the rule is different: **drop them.** There is no label to train on, and guessing one would add noise. Record how many were dropped. If it is more than a few percent, go back and fix the prompt's format instructions.

## Teacher labels contain mistakes

Suppose the teacher is right 80% of the time. Then about one training label in five is wrong.

  options={["Exactly 80%: a student cannot beat its teacher", "Well below 80%, because the errors pile up", "It can end up a little above 80%, though you should not count on it"]}
>
  It can end up a little above the teacher. When the teacher's mistakes are scattered, the student sees many correct examples of each pattern and a few contradicting ones, and the correct pattern wins. The 616 human labels help too. But a teacher that makes the same mistake every time, such as always confusing two types, passes that mistake straight on. Scattered errors get averaged away; consistent errors get copied.
</PredictReveal>

This is why the teacher's per-type scores matter more than its overall accuracy. A teacher at 80% whose errors are spread evenly is a better teacher than one at 85% that never gets three particular types right.

## Checking quality without true labels

In a real project the pool has no true labels, so you cannot measure the teacher's accuracy on it directly. Three checks still work:

- **Read a sample.** Pull 50 labelled messages at random and check them yourself. It takes ten minutes and catches most systematic problems.
- **Count the types.** If the teacher gives one type to a fifth of the pool and another to almost nothing, find out why. Real imbalance is possible, and so is a prompt problem.
- **Ask twice.** Label a sample with two different prompts, or two different sets of examples. Messages where the answers disagree are where the teacher is unsure. A high rate of disagreement is a warning.

In this course the pool's true labels are stored, so the lab can show you the teacher's real accuracy on the pool after the fact. Treat that as the answer key at the back of the book: useful for learning, not available at work.

## How much to label

More labelled messages help, with diminishing returns: the first thousand matter far more than the ninth. Since cost grows in a straight line with the number of messages, it is worth labelling a part of the pool, training, and looking at the result before paying for the rest. The lab labels 3,000 messages by default so that it finishes in reasonable time.

Every project in this course comes down to two choices. This lesson lays them out. Later modules fill in each one.

## Choice one: what does the teacher give you?

**Black-box.** You can only reach the teacher through an API that returns text. You send inputs, collect the teacher's answers, and train the student on those answers as if they were labels. This is how you learn from frontier models you cannot download.

**White-box.** You have the teacher's weights, so you can read its full list of probabilities for every token. The student is trained to match those probabilities, which carry more information than a single answer. This needs an open-weight teacher.

## Choice two: how do you update the student?

**Full fine-tuning.** Every weight in the student is allowed to move. This is simple and gives the best results, but memory use grows with model size.

**LoRA.** The student's weights are frozen and a small set of added matrices is trained. It needs far less GPU memory, so a larger student fits on one card.

## The five steps

Whichever cell you are in, the work follows the same order.

The first step is the one most often skipped. Without a student trained on human labels alone, you cannot show that the teacher added anything. Module 2 is about getting those numbers right before any distillation happens.

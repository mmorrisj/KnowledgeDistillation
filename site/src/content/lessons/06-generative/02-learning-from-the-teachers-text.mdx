The simplest way to distill a writer is the one you already know from Module 4: have the teacher do the task on many inputs, and train the student on what it wrote. For text output this is called <mark>sequence-level distillation</mark>.

Nothing about this needs the teacher's weights. It works with an API teacher, and with a teacher from a different model family.

## Filter before you train

In Module 4 an unusable reply was one that named no valid type. For titles, "unusable" is whatever breaks the task's rules. Those rules can be checked by a program, and a title that breaks them should not be a training example:

- more than eight words;
- empty;
- the customer's message copied back.

A student trained on titles that sometimes run long will write titles that sometimes run long. Filtering costs a little data and removes the teacher's rule-breaking from what the student copies.

This is one of the few places where a student can be made better than its teacher on purpose: on any property you can check by rule.

## The student's prompt

The teacher needs the full instructions every time: what a title is, the word limit, the tone. The trained student has learned all of that from examples, so its prompt is just the message.

That difference is paid back on every request the student ever serves. It is also a reason to distill even when the small model could be prompted into doing the task: a prompted small model pays for the instructions each time and usually follows them less reliably.

## How the teacher writes matters

When collecting training data, have the teacher pick its most likely token at each step, with no randomness. Consistent outputs are easier for a small student to learn than varied ones. If you later want a student with more variety, that is a deliberate choice to make, with more data.

## What this method cannot see

The student sees the title the teacher chose. It does not see that the teacher nearly wrote "delayed" in place of "not received", or that it was unsure whether to mention the three weeks. That is the same loss as in Module 4, and the next lesson recovers it.

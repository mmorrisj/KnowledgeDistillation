Everything so far has been about text. This module asks how much of it survives when the input is an image. The answer is nearly all of it, and seeing that is the point of the module.

## An image as a row of tokens

Module 1 described how a transformer reads text: split it into tokens, turn each token into a list of numbers, and let the model relate them to each other. A <mark>vision transformer</mark> does the same with an image. It cuts the image into small square <mark>patches</mark>, turns each patch into a list of numbers, and treats the patches as tokens.

After that first step, the model inside is the same kind of transformer you have been training since Module 2. One extra token is added to stand for the whole image, and the classifier reads its answer from that token.

## What is new

- **Images are bigger than sentences.** A message was a few dozen tokens. An image is about 200. Preparing images takes real time, so the lab converts them to model-ready numbers once and reuses them.
- **Variety comes from the images themselves.** A photo mirrored left to right is still the same animal. Showing the student altered copies, called <mark>augmentation</mark>, is a standard way to stretch a small set of images. Lesson 8.3 covers how it interacts with a teacher.
- **The teacher is a different kind of model.** It was trained on images paired with text, which is what lets it classify from class names. Lesson 8.2 explains it.

## The task

The data is the Oxford-IIIT Pet dataset: about 7,400 photos of cats and dogs from 37 breeds. Telling a Birman from a Ragdoll, or one terrier from another, is fine-grained in the way the banking types were.

The scenario is the one from Module 2, with images:

<div class="table-wrap">

| Pile | Size | What it is |
|---|---|---|
| Gold training set | 148 (4 per breed) | The few photos a person has labelled |
| Gold validation set | 74 (2 per breed) | Labelled photos for decisions during training |
| Unlabelled pool | about 3,450 | Photos with no human label, for the teacher to score |
| Test set | 1,000 | Held back for scoring finished models |

</div>

Four labelled photos per breed is very little. That is the situation distillation is for.

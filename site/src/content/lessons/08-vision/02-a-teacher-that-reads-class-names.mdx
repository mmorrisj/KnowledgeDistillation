In Module 2 the teacher was a language model given a list of types. For images there is a teacher that plays the same role: it has never been trained on pet breeds as a task, and it can still name them.

## Images and text in one space

The teacher in this module is CLIP. It was trained on hundreds of millions of images paired with the text that accompanied them. It has two halves:

- an image half that turns a picture into a list of numbers;
- a text half that turns a sentence into a list of numbers of the same length.

Training pushed the two halves to agree: a photo of a beagle and the words "a photo of a beagle" end up with similar numbers, and a photo of a beagle and "a photo of a teapot" end up far apart.

## Classifying with no training

That agreement is enough to classify. Write one sentence per class, and for each image ask which sentence it sits closest to.

<PipelineDiagram
  steps={[
    { label: "Write a sentence per class", detail: "“a photo of a beagle, a type of pet”, and so on for all 37 breeds." },
    { label: "Encode the sentences", detail: "The text half turns each into numbers. Done once." },
    { label: "Encode the image", detail: "The image half does the same for the photo." },

    { label: "Softmax", detail: "Turn the 37 scores into probabilities that add up to 100%." },
  ]}
/>

This is called <mark>zero-shot</mark> classification: zero labelled examples of the task were used. It is the image counterpart of the prompted teacher from Module 2, with one advantage. Because the model produces a score for every class in a single pass, you get its full set of probabilities directly. There is no need for the scoring method of lesson 3.2.

## The sentence matters

  The full sentence, usually by several points. The teacher learned from captions, which read like sentences, and the extra words remove ambiguity: a boxer is also an athlete, and a pug is also a kind of nose. The wording is the image teacher's prompt, and like the prompts in Module 4 it is chosen on validation data.

## A licence note

At the time of writing, its page on the model hub carries no licence tag, while the code it was released with is under a permissive licence. Before using it for anything commercial, read its model card and decide whether that is clear enough for your organization. Other image-and-text models with explicit permissive licences exist, and the course code takes the teacher's name as a setting so that you can swap one in.

## Do teacher and student need to match?

No. As in Module 3, the two models' numbers line up by class, not by token or patch. The teacher and the student can cut the image into different patch sizes, expect different image sizes, and be entirely different designs.

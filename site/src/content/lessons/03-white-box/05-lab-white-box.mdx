This lab produces the third number. It needs the results from the Module 2 lab, so run that first.

## What the lab does

1. **Scores every message with the teacher**: the pool, the gold sets and the test set. This is the slow step. The scores are saved, so it runs once.
2. **Scores the teacher itself** using its top choice on the test set. This is the ceiling for this module.
3. **Trains a student on the teacher's top answers** for the pool, treated as if they were labels. This uses only what a text API could have given you.
4. **Trains a student on the teacher's probabilities**, with the distillation loss from lesson 3.4.
5. **Compares everything**: baseline, both students, and the teacher, with intervals, gap closed, and paired tests.
6. **Tries other temperatures**, choosing on the validation set.

## Before you look at the results

Predict two things and write them down:

- How much of the gap between the baseline and the teacher will the probability-trained student close?
- Will it beat the student trained on the teacher's top answers? By how much?

## Reading the results

- **Gap closed.** Above zero means the teacher taught the student something. Compare your figure with your prediction.
- **Probabilities against top answers.** Both students saw the same messages and the same teacher. The only difference is whether the student saw the teacher's full distribution or just its first choice. The paired comparison tells you whether that difference is real. This is the measured value of dark knowledge on this task.
- **The teacher's two scores.** The teacher's score from choosing the most likely type may differ a little from its Module 2 score, where it wrote out an answer. Scoring cannot produce an unusable reply, so it is often slightly higher.

A small or unclear gain from probabilities over top answers is a legitimate result. It would tell you that for this task most of the teacher's value is in its answers, which is good news if your teacher is behind an API. Module 4 picks up from there.

## If something goes wrong

<div class="table-wrap">

| What you see | Likely cause | What to do |
|---|---|---|
| "No result named baseline_gold_616" | The Module 2 lab has not been run on this machine | Run the Module 2 lab first |
| "The scores were computed for different texts" | The saved scores belong to a different split | Delete the named file and run the scoring cell again |
| Out of memory during scoring | Another model is still on the GPU | Restart the notebook and run from the top; saved scores are kept |
| Scoring is slower than expected | It is the slow step, and runs once | Leave it running; progress is printed every 500 messages |

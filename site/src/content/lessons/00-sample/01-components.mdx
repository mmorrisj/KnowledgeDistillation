## Soft targets in one paragraph

A hard label tells the student only that the answer is "mat". The teacher's probabilities say more: "floor" and "rug" are reasonable, "banana" is not. Hinton called this <mark>dark knowledge</mark>, and it is most of what the student learns from.

## Worked example

Code is shown complete first, with numbered notes beside it. Later lessons leave gaps for the student to fill.

<WorkedExample
  title="The distillation loss"
  notes={[
    "Teacher and student use the same temperature T.",
    "kl_div expects log-probabilities as its first argument. Getting this wrong is the most common bug.",
    "Gradients shrink by about 1/T². Multiplying by T² keeps the loss on a similar scale as you tune T.",
    "alpha balances learning from the teacher against learning from the true labels.",
  ]}
>

```python
def kd_loss(s_logits, t_logits, labels, T=2.0, alpha=0.5):
    soft_t = F.softmax(t_logits / T, dim=-1)          # 1
    log_s = F.log_softmax(s_logits / T, dim=-1)       # 2
    kd = F.kl_div(log_s, soft_t,
                  reduction="batchmean") * T**2       # 3
    ce = F.cross_entropy(s_logits, labels)
    return alpha * kd + (1 - alpha) * ce              # 4
```

</WorkedExample>

## Predict first

Students commit to a guess before they see the result. Being wrong first makes the explanation stick.

<PredictReveal
  client:load

  options={["It stays near 0%", "It rises, but stays the least likely", "It overtakes “roof”"]}
>
  It rises from about 0.002% to roughly 7%, but it stays the least likely word. Dividing every score by the same temperature changes how confident the teacher looks. It cannot change the order.
